# 3. Data Presentation

**Difficulty Level:** Beginner

---

# Overview

In this guided Tableau project, you'll take on the role of a **Business Analyst** responsible for exploring customer acquisition and marketing data to generate actionable business insights. Using **Tableau Desktop**, you'll design professional, interactive dashboards that enable stakeholders to understand customer behaviour, evaluate marketing channel performance, and identify trends in subscriber engagement.

Throughout the project, you'll apply Tableau data visualisation best practices to create intuitive dashboards featuring dynamic filters, interactive elements, calculated fields, and business-focused visualisations. The completed dashboard will demonstrate your ability to transform raw data into meaningful insights while strengthening essential business intelligence and data storytelling skills.

# Step-by-Step Instructions

## 1. Import and Clean the Conversion Funnel Dataset

- Connect Tableau to the Excel dataset
- Review data types
- Convert date fields where required
- Validate dimensions and measures
- Identify missing values and data quality issues

---

## 2. Create Visualisations to Analyse Key Performance Metrics

Develop several business-focused worksheets including:

- Customer Signups by Marketing Channel
- Weekly Signup Trend
- Customer Personas
- Customer Conversion & Engagement Rates

Use appropriate chart types to communicate each business question effectively.

---

## 3. Design Interactive Dashboards

Create an executive dashboard by combining multiple worksheets.

Implement interactive features including:

- Country filter
- Marketing Channel filter
- Customer Persona filter
- Week Joined filter

Configure dashboard actions so all visualisations respond dynamically to user selections.

---

## 4. Add Annotations and Highlights

Improve dashboard readability by:

- Adding informative chart titles
- Applying meaningful colour palettes
- Highlighting important business metrics
- Displaying KPI cards
- Formatting labels for improved clarity

---

## 5. Build a Professional Dashboard

Combine all worksheets into a cohesive executive dashboard using Tableau containers.

The completed dashboard should include:

- Executive KPI Cards
- Marketing Channel Performance
- Weekly Signup Trend
- Customer Persona Analysis
- Customer Conversion & Engagement Metrics
- Interactive Filters

---

## 6. Summarise Findings and Recommendations

Interpret the visualisations and provide business recommendations based on your analysis.

Example recommendations may include:

- Improve marketing attribution
- Increase subscription conversion rates
- Enhance customer segmentation
- Monitor acquisition trends
- Improve subscriber engagement
